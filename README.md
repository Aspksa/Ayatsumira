# Ayatsumira

Сайт личного помощника автора. Одностраничный статический сайт (`index.html`) — без сборки и зависимостей.

## Локальный запуск

Откройте `index.html` в браузере или поднимите любой статический сервер:

```bash
python -m http.server 8000
```

## Публикация

Сайт готов к GitHub Pages: Settings → Pages → Deploy from branch → `main` / `root`.
